One line of patch notes announcing that human sleep has been fixed, funny
enough to make a reader laugh and plausible enough to sit in a real
changelog. A judge model compares the lines two at a time and keeps the
funnier one.

> Sleep no longer crashes at 3 a.m. with the error 'remember that embarrassing thing you did in 2012?'

The line was chosen by a local single-elimination tournament over 18 fresh
candidates, scored on the judge brief's five criteria in order: reads as a
real patch note about fixing human sleep; lands a real joke on a single
read; sounds like genuine release notes; stays one line under the cap; and
finds a specific, surprising fix rather than a flat claim. It won 4 of 4
pairings, beating the "brains now ship with a mute button" line in the
final. See `CANDIDATES.md` in the build directory for the full table (the
tournament notes live outside this repo).

## Run it

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
